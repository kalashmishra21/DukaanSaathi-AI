# Future 3D UI brief

Create the Saathi Core only after the product shell and interaction states are defined. The object should communicate idle, listening, reasoning, executing, speaking, and retry states. Let inventory, ₹, khata, and sales concepts appear only when the narrative explains their relationship to the core. Use a lightweight mobile and reduced-motion fallback. Follow the palette, type hierarchy, accessibility rules, and prohibitions in `DESIGN.md`.
